MediNote – Intelligent Medical Visit Note Manager
Overview
MediNote is an AI-powered platform that automatically transforms unstructured medical visit notes into reliable, compliant, and actionable CRM data — without increasing the workload of medical representatives or compromising confidentiality.

Developed as part of the PIDS – 4th Year Data Science Program at Esprit School of Engineering (Academic Year 2025–2026).

Features
AI-powered medical note correction and structuring
Voice-to-text transcription
Automatic CRM data extraction
Next Best Action recommendation engine
Intelligent chatbot assistant
Performance dashboards and reporting
